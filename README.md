# 電影院訂票系統 (Cinema Booking System)

本專題以 C++ 語言開發一套運作於終端機 (CLI) 環境下的「電影院訂票系統」。旨在模擬現代電影院線的核心營運邏輯，包含上片管理、現場訂票、退票紀錄維護以及資料庫之永續儲存。

## 🛠️ 核心技術指標
本系統在架構設計上嚴格落實四大核心技術：
1. **C++ 類別繼承與多型 (Inheritance & Polymorphism)**：實作會員制折扣。
2. **檔案讀寫與資料永續 (File I/O)**：儲存電影與訂票紀錄，防止資料遺失。
3. **STL 容器應用**：使用 `std::vector` 等容器動態管理記憶體與實體資料。
4. **終端機 UI 模擬**：設計流暢的 CLI 互動選單。

---

## 📐 核心類別設計 (OOP Architecture)

### 1. 類別繼承鏈 (User Hierarchy)
系統透過繼承與虛擬函式實作多型折扣計算：
- `NormalMember`：一般會員，無折扣。
- `VIPMember`：VIP 會員，享有 8 折優惠。

### 2. 實體資料類別
- `Movie` 類別：管理電影名稱、類型、片長、基本票價等資訊。
- `Ticket` 類別：管理訂票資訊、座位號碼及最終計算票價。

### 3. 核心控制類別
- `CinemaSystem`：系統控制中心，負責處理 UI 選單邏輯、STL 容器維護及檔案 I/O。
